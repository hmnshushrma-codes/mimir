Watch your AI agents work

Mimir turns Claude Code sessions into a live workshop: the Foreman and every subagent sit at their own desks, and you see each tool call, delegation, permission request, error, and celebration as it happens.

Get started Try the live demo

Quick start

Mimir needs Node.js 22.13 or newer (it uses Node's built-in SQLite).

From npm

npx mimir-dev install   # Wire up Claude Code hooks (one-time)
npx mimir-dev           # Start the visualization

From source

git clone https://github.com/hmnshushrma-codes/mimir.git
cd mimir
nvm use                 # optional — picks Node 22 from .nvmrc
pnpm bootstrap          # install, build, and put `mimir` on your PATH
mimir install           # Wire up Claude Code hooks (one-time)
mimir start             # Start the visualization

Mimir opens http://localhost:4000 in your browser. Start (or restart) a Claude Code session and watch the agents appear.

Hooks are read when Claude Code starts, so restart any Claude Code session that was already open before mimir install.

The workshop

Every Claude Code session gets a room, grouped by project. Inside it:

Foreman

Your main agent, at the big desk with a laptop and coffee mug.

Workers

Subagents spawn at smaller desks, labelled with their role, and leave when done.

You

Your prompts arrive at the user desk next to the Foreman.

Session tools

  • Timeline — chronological tool calls for a session.
  • Historical replay — play, pause, and step through past sessions.
  • Session comparison — side-by-side metrics for two sessions.
  • Permission queue — pending approvals with the agent and tool waiting on them.
  • Search & notes — search tool calls, commands, and files across history; keep notes per project.

Analytics

The Analytics tab summarizes everything Mimir has recorded. It all runs locally and deterministically — no LLM calls.

Token & cost intelligence

The Tokens tab reads Claude Code transcript files and shows usage in terms anyone can understand — conversations, words, and memory percentage instead of raw token counts. Cost estimates are clearly labeled as API-equivalent (not your actual bill on Pro/Max plans).

Permission approval

When Claude Code asks for permission, a docked panel shows the full command, file, or URL being requested. Click Allow, Deny, or decide in the terminal — first answer wins. Destructive commands (rm -rf, force push, drop table) are highlighted and require double-confirm. The mascot's YES/NO signs are also clickable.

Tool analytics

Most-used tools, success and failure rates, average duration, retries.

Tokens & cost

Plain-English token dashboard with memory gauge, cost breakdown, and savings tips.

Permission approval

Remote allow/deny from the browser with risk tags, secret redaction, and audit log.

Prompt quality

A 10-dimension score for each prompt, with suggestions to improve it.

Knowledge

CLAUDE.md detection, frequently accessed files, and gaps worth documenting.

Permissions history

Every request from pending to approved or cancelled, with how long it waited.

Commands

CommandWhat it does
mimir / mimir startStart the collector and web UI
mimir demoStart with simulated data — no Claude Code session needed
mimir installInstall Claude Code hooks for your user
mimir install --projectInstall hooks for the current project only
mimir uninstallRemove Mimir's hooks (other tools' hooks are left alone)
mimir statusShow where hooks are installed and whether the collector is reachable
mimir replay-summaryPrint a per-agent breakdown of time spent in each state

With npx, prefix each command: npx mimir-dev status.

How it works

Claude Code hooks ──▶ POST /events ──▶ Collector (Fastify) ──▶ WebSocket ──▶ React app
                                            │                                  │
                                         SQLite                            Analytics
                                       (event log)                  (tokens, cost, waste,
                                                                     prompts, knowledge)
  1. Claude Code fires hook events — tool calls, subagent starts and stops, permission requests.
  2. A small hook script, installed to ~/.claude/agent-workshop/, posts each event to the local collector.
  3. The collector normalizes the event, stores it in SQLite, and updates analytics.
  4. The web app receives updates over WebSocket and animates the workshop.

Configuration

All settings are optional environment variables:

VariableDefaultDescription
AGENT_WORKSHOP_PORT4000Server port
AGENT_WORKSHOP_HOST127.0.0.1Bind address
AGENT_WORKSHOP_PREVIEWStrueStore short previews of tool input and output
AGENT_WORKSHOP_IDLE_MS120000How long before an idle agent falls asleep
AGENT_WORKSHOP_DEPART_AFTER_MS7000How long a finished agent lingers before leaving

A friendlier URL

Map mimir.local to your machine once, and Mimir will use it automatically:

echo "127.0.0.1 mimir.local" | sudo tee -a /etc/hosts

Privacy

  • Everything stays on your machine. Hooks only talk to 127.0.0.1; Mimir makes no external network calls.
  • Tool input and output are stored as short previews (500 characters). Set AGENT_WORKSHOP_PREVIEWS=false to store none.
  • Token data from transcripts is opt-in and never leaves your machine.
  • mimir uninstall removes all of Mimir's hooks and never touches hooks from other tools.

Demo mode

The live demo runs entirely in your browser with a simulated 75-second session — three subagents, an error and retry, and a permission prompt, on a loop. It never connects to a server.

Use the control bar to trigger events yourself:

ButtonWhat happens
✋ PermissionAn agent raises its hand, waiting for approval
➕ Spawn AgentA new subagent takes a desk
💥 ErrorA tool call fails and the agent scratches its head
✅ FinishThe session wraps up and everyone celebrates

Run the same demo locally with npx mimir-dev demo.

Troubleshooting

mimir: command not found

Building from source doesn't put mimir on your PATH by itself. Run pnpm bootstrap (or node scripts/link-cli.mjs after a build), or use pnpm start from the repo.

"mimir requires Node >= 22.13"

Mimir uses Node's built-in SQLite. Upgrade with nvm install 22 && nvm use 22, and make it the default with nvm alias default 22.

The browser opens but nothing appears

Run mimir status. If hooks show "not installed", run mimir install, then restart Claude Code. If the collector is "not reachable", make sure mimir start is still running.

mimir.local doesn't load

.local names only resolve if you've mapped them. Use http://localhost:4000, or add the hosts entry from Configuration.

Port 4000 is already in use

Start on another port: AGENT_WORKSHOP_PORT=4100 mimir start.
